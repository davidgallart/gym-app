# Gym App David Gallart

App React + Vite + Supabase para registrar marcas de gimnasio desde el móvil.

## Incluye

- Login/registro con Supabase Auth.
- Apartado independiente para crear, editar y borrar ejercicios.
- Registro de entrenamientos con ejercicios, peso y repeticiones.
- Última marca visible al seleccionar un ejercicio.
- Historial de entrenos.
- Edición de fecha, pesos y repeticiones de entrenos guardados.
- Borrado de entrenamientos guardados.
- Gráficas de progreso por ejercicio.
- Diseño mobile-first, responsive, oscuro y con acento rojo.
- Toasts para avisos.

## Arranque

```bash
npm install
npm run dev
```
